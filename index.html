Cómo funciona

Un script vigila el fondo actual. Cuando cambia, busca el tema con el mismo nombre y reparte sus colores a todo lo demás.

1Fondo .mp4Serpantinum lo reproduce; cambia solo cada 2 h (claros de día, oscuros de noche)
→
2Tema .json22 colores estilo Catppuccin hechos a mano para cada fondo
→
3wallpaper-theme.shaplica la paleta y lanza los sincronizadores

Las piezas

Base

  • Arch Linux · kernel 7.3
  • Hyprland con configuración en Lua
  • Serpantinum (Quickshell): barra, widgets, bloqueo
  • systemd-boot + Plymouth con nieve
  • SDDM astronaut, sigue al tema

  • kitty + starship + fastfetch
  • rofi (juegos y apagado)
  • VS Code, Obsidian, Spotify (Spicetify)
  • Vesktop con el fondo de fondo
  • GTK, Qt, Dolphin, Papirus, Brave
